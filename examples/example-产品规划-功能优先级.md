# 实测示例：产品规划 — 做 B 端企业版，还是深耕 C 端转化？

> 演示：把 `mao-thinking.md` 作为系统提示后，给一个产品规划难题，AI 按标准模板产出如下分析。

## 用户提问
"我们是一款面向个人的笔记 App，50w 用户，免费+订阅，付费转化率只有 2%。团队 8 人。现在纠结：A) 做企业版（B 端协同）打开新收入，还是 B) 深耕 C 端留存与转化？资源有限，只能选一个方向。竞品在 B 端已占先。"

---

## AI 输出的分析（方法论驱动）

【客观事实】
- C 端：50w 用户，ARPU 低，付费转化 2%；近两季度留存持平。
- B 端：竞品已占先发，销售周期长（6–12 月），需地推/客成能力。
- 团队：8 人，纯消费级基因，零 B 端经验；现金可撑 18 个月。

【矛盾清单】
1. C 端深耕 vs B 端扩张
2. 短期收入 vs 长期壁垒
3. 团队基因（消费级）vs B 端能力缺口
4. 资源有限，只能单选

【主要矛盾】
"哪个方向能形成**与团队基因匹配、可持续的增长飞轮**"——不先定这个，做 A 或 B 都可能是'在错误战场用错误能力'。真正的矛盾不是'A 还是 B'，而是'我们是否在用短板打别人的长板'。

【主要矛盾方面】
决定性质的是**团队能力与市场的匹配度**，而非'市场大小'。B 端市场大，但团队无基因，强行进入 = 把'集中优势兵力'用在了劣势战场。

【主客观校核】
- 主观：易被'B 端客单价高'诱入（只看利好，速胜倾向）。
- 客观：零 B 端经验、销售周期长、竞品强、现金仅 18 个月——不具备速胜条件。
- 偏差修正：放弃'一口吃成胖子'，回到'集中优势兵力于己方强点'。

【战略方向】
不四面出击。用'集中优势兵力'先把 C 端转化这个最短板从 2% 提到 4%（量变质变：转化率的积累到跃迁），同时用'一般与个别结合'在小范围试水 B 端（试点 2–3 个团队）验证需求，**不 All-in**。

【战术选择】
- 集中优势兵力：聚焦 C 端转化这一个最短板
- 量变质变：转化率的持续积累→跃迁
- 弹钢琴：C/B 兼顾但主次分明
- 一般与个别结合：B 端先试点再判断

【行动拆解】
- 本月：上线付费转化漏斗 3 个 A/B 实验
- 同期：邀 2 家企业内测，只观察留存不复制功能
- 每两周复盘数据

【复盘机制】
C 端转化率提升 → 加大投入；B 端试点留存差 → 放弃扩张，回归 C 端长板。

---

## 实测结论
框架在该题上避免了'看市场大就冲 B 端'的直觉陷阱，强制回到'集中优势兵力于己方强点'的战略纪律，并用'量变质变 + 一般与个别'给出可执行的渐进路径——这正是产品规划中最常被忽视的'能力与战场匹配'问题。

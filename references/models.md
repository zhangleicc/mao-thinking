# 毛选思维模型详解（21 个）

每个模型含：核心定义、拆解步骤、历史案例、现代应用。调用时按需读取对应条目。

---

## 1. 实事求是 / 调查研究

**核心**：客观事实是思想最底层的存在。思想不依据事实→空想、假道理→失败；思想符合事实→正确思想→成功行动。"没有调查，就没有发言权"。

**四步拆解**
1. 准备——定好题目、选好典型、列好纲目（如《寻乌调查》选三省交界的寻乌为典型）
2. 深入——亲身求事，开调查会，找知情人座谈（毛泽东选 8 位兴国籍红军战士座谈 7 天写《兴国调查》）
3. 求真——放下预设，让事实说话，反对"本本主义"
4. 结论——形成有科学依据的判断，指导行动

**案例**：《兴国调查》（1930，四万字，为土地革命找科学依据）；《寻乌调查》（1930，八万字，摸清华南商业与富农问题）。

**现代应用**：做决策前先核实数据；用户研究先访谈再结论；别用"我觉得"替代"事实是什么"。

---

## 2. 实践循环

**核心**：认识源于实践，经历"实践→感性认识→理性认识→再实践"螺旋上升。反对脱离实际的教条与空想。

**四步拆解**
1. 投入实践——获得感性材料（毛泽东先调查研究，而非坐办公室"发明"理论）
2. 上升理性——从感性经验提炼规律
3. 回到实践——用理性认识指导新实践
4. 检验修正——实践结果检验认识，再认识

**案例**：延安文艺座谈会——先调研文艺界分歧，再形成《讲话》方向，再指导创作。

**现代应用**：学技能先动手再系统学；项目先小范围试点再铺开；MVP 思维。

---

## 3. 矛盾法则

**核心**：对立统一是宇宙根本规律。矛盾无处不在（普遍性）、不同事物/阶段各不相同（特殊性）。解决问题先抓主要矛盾与主要方面。

**四步拆解（四层漏斗法）**
1. 列矛盾清单（显微镜思维）——书面列出所有冲突
2. 抓主要矛盾（找牛鼻子）——哪个决定全局
3. 分析矛盾主要方面——决定性质的那一面
4. 具体问题具体分析——不照搬、不一刀切

**案例**：大庆油田会战（1960）——在外国专家撤走、极端严寒等重重矛盾中，以《实践论》《矛盾论》指导，认准"靠两论起家"解决根本矛盾。

**现代应用**：任务太多时问"哪个不解决后面全动不了"；关系/职场困局先分清主次矛盾。

---

## 4. 弹钢琴

**核心**：统筹兼顾，十个指头都动，但要有主有次、有节奏。反对只抓一点、单打一。

**五步拆解**
1. 十个指头都动——识别系统里所有要兼顾的要素
2. 分清主次——哪几个是重音
3. 把握节奏——轻重缓急的时序
4. 协调配合——让各要素相互支撑而非打架
5. 突出重点——在兼顾中保证主攻方向

**案例**：《论十大关系》（1956）——重工业与轻工业农业、沿海与内地、中央与地方、汉族与少数民族等十对关系统筹处理。

**现代应用**：工作生活平衡；多项目并行时排优先级；管理既要抓业务也要抓团队。

---

## 5. 集中优势兵力

**核心**：总体劣势下不平均用力，把力量集中到最关键战场/时机/敌人，形成局部绝对优势，各个歼灭，积小胜为大胜。

**五步拆解**
1. 选准目标——"打谁"，找准薄弱或关键节点
2. 集中聚力——在决定点形成压倒性优势
3. 各个歼灭——不四面出击，逐个解决
4. 把握时机——等敌分散或露出破绽
5. 转化态势——局部胜势滚雪球为战略主动

**案例**：孟良崮战役（1947）——"百万军中取上将首级"，集中兵力歼灭国民党整编 74 师。

**现代应用**：资源有限时聚焦单点突破；求职/创业先做透一个细分；别同时追十个目标。

---

## 6. 辩证加工

**核心**：对材料做"去粗取精、去伪存真、由此及彼、由表及里"的加工，从现象到本质。

**四步拆解**
1. 去粗取精——筛选关键材料，舍去次要
2. 去伪存真——辨别真假，剔除干扰
3. 由此及彼——建立联系，看整体
4. 由表及里——穿透表层，抓本质规律

**案例**：毛泽东解读蒋介石"不进不出"模糊密电（1947），用十六字诀洞察其深层战略心态。

**现代应用**：读报告/看新闻时辨真假、找重点；从杂乱信息提炼核心结论。

---

## 7. 统筹兼顾

**核心**：在复杂系统中兼顾多重要素，既顾此又不失彼，在矛盾间找平衡。

**四步拆解**
1. 系统识别——看清有哪些要素要兼顾
2. 区分权重——哪些关乎生存、哪些关乎发展
3. 协调布局——时空上错开、资源上配比
4. 动态调适——随形势调整兼顾的重心

**案例**："三线建设"（60 年代）——既要备战（国防），又要发展（经济）；既用沿海基础，又开发内地。

**现代应用**：公司短期业绩与长期投入的平衡；个人赚钱与成长的兼顾。

---

## 8. 全局统率局部

**核心**：站在高处看全局，先打对全局有决定意义的点，不为局部得失所惑。

**四步拆解**
1. 建立全局意识——"站在高处看"
2. 识别枢纽——哪个局部决定全局
3. 牺牲局部保全局——敢于放弃次要
4. 推动全局转化——拿下枢纽带动整体

**案例**：辽沈战役先打锦州（1948）——多数将领主张先打近且有把握的长春，毛泽东坚持先打远且险但锁死全局的锦州。

**现代应用**：职业选择看赛道而非眼前薪资；产品先打透核心场景再扩展。

---

## 9. 调查研究（方法版）

**核心**：详见模型 1。此处强调操作规范：定题目、选典型、列纲目、亲身求事。

**现代应用**：用户访谈、市场调研、竞品分析的标准动作。

---

## 10. 胸中有数

**核心**：一切以数量界限为依据，"对情况和问题一定要注意到它们的数量方面，要有基本的数量分析"。

**四步拆解**
1. 建立数量意识——习惯看数，不靠"大概"
2. 精确统计——到个位数（兵力、时间、空间、物资）
3. 数量对比——敌我优劣用数据说话
4. 定量化决策——以数定方案

**案例**：淮海战役——毛泽东与军委对兵力、物资、时间、空间做精确到个位数的数量分析。

**现代应用**：用数据而非感觉做判断；设指标、看趋势、定阈值。

---

## 11. 夺取主动权

**核心**：在被动中创造主动，"我打我的、你打你的"，不被敌人节奏带跑。

**四步拆解**
1. 主动意识——"我要主动"，不被被动压倒
2. 调动敌人——让对手随我节奏
3. 创造条件——制造有利于我的态势
4. 掌握枢纽——抓关键扭转被动

**案例**：四渡赤水（1935）——3 万对 40 万，变被动为主动的经典。

**现代应用**：职场中被牵着走时主动设议程；谈判中先出框架。

---

## 12. 感性—理性飞跃

**核心**：丰富实践经验需上升为系统理性认识，否则只是零散直觉。

**四步拆解**
1. 感性阶段——积累丰富实践经验
2. 归纳提炼——找共性规律
3. 理性飞跃——形成系统认识
4. 指导实践——用理性反哺行动

**案例**：毛泽东在抗大讲授《实践论》，帮走过长征的红军干部完成从感性到理性的飞跃。

**现代应用**：复盘沉淀方法论；老手带新人讲"为什么"而非只讲"怎么做"。

---

## 13. 善于总结经验

**核心**：打一仗进一步，"从战争中学习战争"，不糊里糊涂。

**五步拆解**
1. 及时总结——每役必总结，不拖延不回避
2. 正视成败——胜在何处、败因何在
3. 提炼规律——可复用的经验
4. 固化方法——变成下次动作
5. 迭代提升——打一仗提高一步

**案例**：四平攻坚战失利（1947）后，部队立即总结教训，李天佑："善于总结经验，从战争中学会打仗。"

**现代应用**：项目复盘会；周报里的"学到了什么"；失败日志。

---

## 14. 创造转化条件

**核心**：矛盾不会自动转化，需主动创造条件，促成向有利方向转化。

**四步拆解**
1. 条件意识——转化需要条件，不会自动到来
2. 分析条件——现状缺什么、有何可借力
3. 主动创造——用有策略的行动争取
4. 促成转化——让矛盾朝目标方向演变

**案例**：重庆谈判（1945）——毛泽东冒风险赴渝，以主动行动创造条件，争取和平、揭露对手、团结舆论。

**现代应用**：想转行先补能力/人脉条件；想谈成先造势。

---

## 15. 灵活机动

**核心**：避实就虚、实事求是、力争主动，不墨守固定计划盲目硬干。

**四步拆解**
1. 从实际出发——不教条规定行动
2. 避实就虚——打敌薄弱
3. 机动应变——计划随情况调整
4. 力争主动——始终掌握行动自由

**案例**：四渡赤水——灵活机动、避实就虚，不再被动挨打、不墨守成规。

**现代应用**：计划赶不上变化时快速调整；创业 pivot；沟通看人下菜。

---

## 16. 预见与阶段划分

**核心**：科学预见趋势，把过程划分为阶段，分步推进。

**四步拆解**
1. 趋势预见——预先看到前途趋向
2. 矛盾分析——把握决定走向的基本矛盾
3. 阶段划分——明确当前在哪个阶段
4. 分步推进——按阶段定任务

**案例**：《论持久战》（1938）——批亡国论与速胜论，科学预见抗战三阶段，后被历史证实。

**现代应用**：个人五年规划分阶段；企业战略路线图；识别"现在处于哪个阶段"。

---

## 17. 群众路线策略

**核心**：从群众中来、到群众中去；一般号召与个别指导结合。

**五步拆解**
1. 深入群众——到现场听真实意见
2. 集中意见——把分散意见化为系统方针
3. 一般号召——把方向讲清楚
4. 个别指导——试点突破、典型示范
5. 回到群众——在实践中检验修正

**案例**：兴国县土地法修订——发现"没收一切土地"伤中农，循群众路线调查修订。

**现代应用**：产品需求来自用户；管理决策下沉听一线；调研驱动迭代。

---

## 18. 主客观统一

**核心**：主观认识要符合客观实际，具体地、历史地看问题，反对主观脱离客观。

**四步拆解**
1. 摸清客观——现实条件、力量对比
2. 校正主观——去掉幻想与恐惧
3. 具体地历史地看——不抽象、不静态
4. 统一于行动——在客观约束下发挥能动

**案例**：《论持久战》——亡国论（主观落后于客观）、速胜论（主观超越客观）皆错，需主客观统一。

**现代应用**：定目标匹配真实资源；评估机会看客观约束。

---

## 19. 量变质变运用

**核心**：强弱转化是量到质的过程，重视积累，把握跃迁节点。

**四步拆解**
1. 识别量变——日常向上的微小变化
2. 保护量变——不让向好积累中断
3. 预判质变——何时发生跃迁
4. 抓住跃迁——在节点上发力

**案例**：《论持久战》抗战三阶段——中国"军队进步、政治进步、人民动员、游击战出现"等质变因素，构成持久与最后胜利的根据。

**现代应用**：复利思维；技能/人脉的积累；识别临界点果断加码。

---

## 20. 一般与个别相结合

**核心**：一般号召与个别指导并重，先试点突破获取经验再推广。

**五步拆解**
1. 一般号召——把方向、方针讲清楚
2. 个别指导——具体单位蹲点示范
3. 试点突破——在小范围验证
4. 总结经验——提炼可推广做法
5. 全面推广——由点及面

**案例**：延安整风（1942）——"凡有成绩者，都是采用了一般与个别相结合的方法"。

**现代应用**：新制度先在小团队试点；变革管理由标杆带动。

---

## 21. 分解因式（克服三分钟热度）

**核心**：大目标=战略方向（只作指引），小目标=战术任务（每日紧盯）。缩小目标差距→积累信心→持续行动→大目标自然达成。

**四步拆解**
1. 锁定大目标——定为战略方向，不天天盯着焦虑
2. 分解因式——拆成每日可完成的小任务
3. 日拱一卒——只盯当天小目标，积累信心
4. 自然达成——持续行动，大目标水到渠成

**原理类比**：数学分解因式；过河需船桥（教员语录）。

**现代应用**：学技能/减肥/改变现状：别被大差距击垮，每日小赢；对抗眼高手低、三分钟热度。

## 配套元模型

- **阳谋思维**：公开目的/逻辑/利益/做法，对方明知无法阻挡。案例：1937 年与贝特兰谈话，对老百姓/国民党/日本/国际社会各讲清战略内核。现代：公开 roadmap 建立信任与势能。
- **重新定义问题**：很多问题是拿来"重构"而非"解决"的——先确认命题本身对不对。
- **打则必胜**：轻易不打，打则必胜；准备不足、出手太快是多数人失败的根因。
- **有理有利有节**：斗争/维权的策略性原则，打破"沉默的螺旋"但把握分寸。

## 模型选择速查（矛盾类型 → 推荐模型）

拿到问题却不知该调用哪个模型时，按"你遇到的情况"查下表，直接定位模型；多个模型可组合使用。（注：知识库中另有一份总览性架构图「00毛选思维模型架构图」作为全局视图；下文逐一拆解的模型为其下的具体方法，实事求是位于首位，但「总览」指的是那份架构图，而非任一单一模型。）

| 你遇到的情况（矛盾类型） | 优先调用模型 |
|------|------|
| 看不清真实情况 / 信息不足 / 拍脑袋决策 | 实事求是 / 调查研究、胸中有数、辩证加工、感性—理性飞跃 |
| 矛盾缠身、分不清主次 | 矛盾法则、全局统率局部、弹钢琴、统筹兼顾 |
| 资源有限、想面面俱到 | 集中优势兵力、弹钢琴、统筹兼顾 |
| 局面被动、被别人牵着走 | 夺取主动权、灵活机动、创造转化条件 |
| 目标太大、无从下手 / 三分钟热度 | 分解因式、预见与阶段划分、量变质变 |
| 想法没验证 / 要试错 / 缺经验 | 实践循环、善于总结经验、一般与个别相结合 |
| 主观预期 vs 客观现实脱节（速胜论/亡国论） | 主客观统一、实事求是 |
| 认知混沌、要从现象到本质 | 感性—理性飞跃、辩证加工、调查研究 |
| 要推动他人 / 团队 / 用户 | 群众路线策略、一般与个别相结合 |
| 长期 vs 短期张力 / 路线规划 | 预见与阶段划分、量变质变、统筹兼顾 |
| 怀疑问题本身可能错了 | 重新定义问题（元模型）、阳谋思维 |

**推荐组合拳（标准调用顺序）**：调查研究 → 矛盾法则（抓主要矛盾）→ 集中优势兵力（定战术）→ 分解因式（行动拆解）→ 实践循环（复盘）。多数复杂问题沿这条线走一遍即可。

# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/), and this project adheres to
semantic versioning.

## [1.2.0] — 2026-08-14

### Added
- `examples.en.md` — **English summary of all four test cases**. Lowers the
  reading barrier for overseas users: one file condenses the solo-dev, product
  planning, interpersonal-game, and tech-strategy examples into English
  (question → principal contradiction → strategy → takeaway).
- `CHANGELOG.md` — this file; the `updated` badge on both READMEs now resolves.

### Docs
- Both `README.md` and `README.en.md` link the English examples summary and
  reference `CHANGELOG.md`.

## [1.1.0] — 2026-08-14

### Added
- `README.en.md` — full English README with a language switcher at the top.
- Three new cross-domain test examples in `examples/`:
  - `example-产品规划-功能优先级.md` — product planning / feature priority.
  - `example-人际博弈-跨部门谈判.md` — interpersonal game / cross-team negotiation.
  - `example-技术战略-技术债重构.md` — tech strategy / tech-debt vs rewrite.

### Docs
- `README.md` gained a language switch and an expanded examples list.

## [1.0.0] — 2026-08-14

### Added
- Initial public release.
- `mao-thinking.md` — universal paste version (single self-contained, de-branded).
- `SKILL.md` — Claude Skills / WorkBuddy compatible (`name`/`description` header).
- `gpt-instructions.md` — OpenAI custom GPT Instructions text.
- `references/models.md` — full breakdown of the 21 thinking models.
- `references/applications.md` — applied-article highlights.
- `examples/example-独立开发者决策.md` — first test example (solo-dev decision).
- `README.md` (Chinese), `LICENSE` (MIT), `.gitignore`.
